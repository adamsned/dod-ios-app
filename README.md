# Dutch Oven Daddy iOS App

Native iPhone + iPad reader for [dutchovendaddy.com](https://www.dutchovendaddy.com).

Built spec-first. See [`specs/`](specs/) for the constitution, spec, plan, and task list — code traces back to them.

## Status

Phase 5 — Implement, Cluster A (scaffolding).

## Prerequisites

```bash
brew install xcodegen swiftlint swift-format
```

- **XcodeGen** generates `DODApp.xcodeproj` from `project.yml`. Never edit the `.xcodeproj` by hand.
- **SwiftLint** runs at build time and in CI. Warnings fail the build.
- **swift-format** is run via `bin/format.sh` or your pre-commit hook.

## First-time setup

```bash
git clone <repo> DODApp
cd DODApp
xcodegen generate     # produces DODApp.xcodeproj
open DODApp.xcodeproj
```

Build target: **DODApp** scheme, any iOS 17+ simulator (iPhone 15 by default).

## Project layout

```
DODApp.xcodeproj/          # generated by XcodeGen — do not commit
App/                       # @main entry, RootView, composition root
Packages/                  # 11 modular Swift Packages
  DODDomain/               # pure value types
  DODSupport/              # tiny utilities
  DODDesignSystem/         # colors, typography, components
  DODAnalytics/            # TelemetryDeck wrapper
  DODNetworking/           # WP REST + JSON-LD parser
  DODPersistence/          # SwiftData cache + saves
  DODFeatureFeed/
  DODFeatureCategories/
  DODFeatureSearch/
  DODFeatureRecipeDetail/
  DODFeatureSaved/
specs/                     # constitution, spec, plan, tasks, clarifications
.github/workflows/         # CI
bin/                       # dev scripts (format, etc.)
```

Each module owns its sources and tests. Layering is compiler-enforced — see [`specs/dod-ios-app/plan.md`](specs/dod-ios-app/plan.md) §1.

## Workflow

1. Pick a task from [`specs/dod-ios-app/tasks.md`](specs/dod-ios-app/tasks.md).
2. Branch: `feat/T-NNN-short-slug` (or `fix/`, `spec/`).
3. PR description cites the T-ID **and** the AC IDs from `spec.md` it implements (constitution §11).
4. CI green + human approval required to merge.

## Formatting

```bash
bin/format.sh             # runs swift-format across the tree
```

## Known limitations (v1.0)

- Saved recipes are device-local. Reinstalling the app wipes them (AC-5.7). iCloud sync is v2.
- Inline videos do not play offline (AC-5.5).
- Search is title + excerpt only; ingredient-body search is v2 (AC-3.2).
